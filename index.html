AK INFO PARK internship · Apr - May 2026

ShopZone is a modern, responsive full-stack e-commerce web application designed to provide a seamless online shopping experience. Built with a React/Next.js dynamic frontend deployed on Vercel, ShopZone features user authentication, dynamic product browsing with smart search and filtering, an interactive shopping cart, and a multi-step checkout workflow.

↗ ShopZone Website Redesign & Full Stack Web Development Intern

My role

As part of my internship at AK Infopark, I independently led the redesign and frontend rebuilding of ShopZone—a full-featured e-commerce platform. While the core ShopZone business logic and existing frontend were already established prior to my arrival, my contribution focused on transforming the overall user interface, optimizing product presentation, and refining the site architecture.

What I worked on

Frontend redesign
  • Overall UI architecture & responsive layouts
  • Visual overhaul of homepage, catalog, and cart
  • Product page presentation & component structure
  • Mobile-first experience across devices
SEO & optimization
  • On-page SEO & client-side metadata setup
  • Keyword-aligned category & product structuring
  • Core Web Vitals & performance tuning
  • Search-intent-led content organization
Catalog & UX polish
  • Product catalog filtering & search presentation
  • Streamlined multi-step checkout user flow
  • Component reusability & clean design hierarchy

Tools & workflow

React Vite JavaScript (ES6+) HTML5 / CSS3 Vercel Git / GitHub Google Search Console

Challenges

Balancing high-performance frontend interactivity with SEO best practices was the primary hurdle. Restructuring the existing e-commerce codebase required simplifying component hierarchies and optimizing image loading without disrupting existing catalog routing or search visibility.

Outcome

This project highlights the technical execution and UI engineering process of rebuilding an e-commerce platform. No specific client sales or conversion metrics are claimed here, as the focus remains strictly on the structural redesign, frontend optimization, and production deployment on Vercel.

What I learned

Owning the complete redesign of an existing e-commerce frontend deepened my understanding of component modularity, state management, and real-world web performance. It sharpened my ability to write clean, maintainable web architecture while delivering a smooth user experience.
